# Baow Tia Villa — House design for Mr Tia

Interactive 3D presentation of the 2-storey villa design (**Rev18**, 24 Oct 2026).

**Live site:** https://anousaksiritham-creator.github.io/Baow-Tia-houses/

## What's in it
- 3D model with preset views, walk-through mode, day / night lighting
- Floor-by-floor plans and the drawing set (A-101 … A-601, S-101)
- Sun study and analysis tabs

## Files
- `index.html` — the full model (source: `tia_villa_3d_rev18.html`)
- `vendor/three-0.169.0/` — local copy of three.js r169 (MIT licence), so the site does not depend on an external CDN

## Status
Design drawing for presentation. Structure and building services must be calculated and signed by a licensed engineer before construction.
